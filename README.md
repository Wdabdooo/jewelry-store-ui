# Luna Jewel UI

واجهة متجر مجوهرات فاخر تم تصميمها كصفحة هبوط عربية أنيقة وعصرية.

## التشغيل

افتح ملف `index.html` مباشرة في المتصفح.

## المميزات

- تصميم فاخر مستوحى من المتاجر الراقية
- ألوان ذهبية، سوداء، وبيج هادئة
- أقسام: Hero، تصنيفات، منتجات مميزة، قصة المتجر، تقييمات، Newsletter
- تفاعل بسيط: إضافة إلى السلة، تنقيح المنتجات، اشتراك النشرة

## الملفات

- `index.html` — هيكل الصفحة
- `styles.css` — التنسيق والستايل
- `script.js` — التفاعلات البسيطة

## الصور

يتم استخدام صور Unsplash مباشرة عبر الروابط الخارجية، لذلك لا حاجة إلى ملفات صور إضافية.
